# NontonGratisan

Katalog film dan serial berbasis web dengan navigasi berdasarkan genre, kategori, dan jenis tontonan.

## Halaman penting

- Beranda: https://nonton-gratisan.vercel.app/
- Sitemap XML: https://nonton-gratisan.vercel.app/sitemap.xml
- Halaman navigasi SEO: https://nonton-gratisan.vercel.app/index-google.html
- Sitemap HTML: https://nonton-gratisan.vercel.app/sitemap.html
- Privacy Policy: https://nonton-gratisan.vercel.app/privacy-policy.html
- Terms: https://nonton-gratisan.vercel.app/terms.html
- Copyright: https://nonton-gratisan.vercel.app/copyright.html
- Contact: https://nonton-gratisan.vercel.app/contact.html
- Dukung: https://nonton-gratisan.vercel.app/dukung.html

## Kategori film

Action, Horror, Comedy, Thriller, Drama, Romance, Sci-Fi, dan Animation.

## Kategori serial

Series Korea, Series Barat, dan Series Indonesia.

## Catatan

Repository ini digunakan untuk menjalankan situs NontonGratisan. File konfigurasi SEO seperti `robots.txt` dan `sitemap.xml` membantu mesin pencari menemukan struktur situs.
